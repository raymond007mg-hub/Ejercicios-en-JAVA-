**Adivina el personaje**

Este ejercicio consiste en desarrollar un programa que permita al usuario elegir uno de los personajes disponibles en una lista. Posteriormente, el programa debe realizar una serie de preguntas al usuario para intentar determinar cuál fue el personaje seleccionado.

El programa debe utilizar preguntas cuya respuesta sea únicamente **"Sí" o "No"**, y mediante las respuestas obtenidas debe identificar el personaje elegido.

Entre los personajes propuestos se encuentran: Rafael, Falcao García, Goku, Michael Jordan, Eminem, Darth Vader, Adán Sandler, Bruce Wayne, Tin Tin, Ayudante de Santa, Joe Biden, José Saramago, Gunter Grass y Kim Jong Un.

**Caballos**

Este ejercicio está relacionado con el movimiento de las piezas en un tablero de ajedrez.

### A. Método `caballoAtacaRey`

Se debe crear un método que reciba como parámetros cuatro valores enteros correspondientes a la posición de un caballo y un rey dentro de un tablero de ajedrez:

- Fila del caballo.
- Columna del caballo.
- Fila del rey.
- Columna del rey.

El método debe determinar si el caballo puede atacar al rey desde las posiciones recibidas y devolver un valor booleano (`true` o `false`) dependiendo del resultado.

### B. Programa principal

El programa debe solicitar al usuario las posiciones del caballo y del rey en el tablero.

Después de recibir los datos, se debe utilizar el método desarrollado en el literal A para determinar si el caballo está atacando al rey y mostrar el resultado correspondiente en pantalla.

**Suma de números primos**

Este ejercicio consiste en desarrollar un programa que solicite al usuario un número entero positivo `n`.

El programa debe identificar los números primos menores o iguales que `n` y calcular la suma de todos ellos.

Finalmente, debe mostrar en pantalla el resultado obtenido a partir de la suma de los números primos encontrados.
